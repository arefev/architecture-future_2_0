| --------------- | --------------------------------------------------------------------- | ----------- | ------- |

| Архитектурный   | Некорректный переход на event-driven (duplicate events, wrong schema) | Средняя     | Среднее |
| Технологический | Низкая производительность ClickHouse при больших потоках              | Средняя     | Высокое |
| Технологический | Нехватка GPU для ИИ                                                   | Низкая      | Среднее |
| Технологический | Неопытность команды в стриминге (Kafka/YMQ)                           | Высокая     | Высокое |
| Организационный | Несогласованность доменных границ                                     | Высокая     | Высокое |
| Организационный | Сопротивление изменениям со стороны медперсонала                      | Средняя     | Среднее |
| Организационный | Недостаток компетенций в CI/CD, Terraform, облаках                    | Средняя     | Среднее |
